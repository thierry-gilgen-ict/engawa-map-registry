Join the map

Listing is voluntary and operator-initiated. Registration is never automatic. The first successful registration is always PENDING; sites appear here only after manual approval.

Install the published CLI client and register from your project root:

npm install --save-dev @thierry-gilgen-ict/engawa-map
npx engawa-map register

The CLI defaults to the production registry when ENGAWA_MAP_ENDPOINT is unset. Engawa-powered websites do not phone home from normal runtime — no telemetry, no automatic crawling, and no browser admin UI.

See the Engawa Distribution Map documentation and @thierry-gilgen-ict/engawa-map@0.1.0 on npm for integration details.
